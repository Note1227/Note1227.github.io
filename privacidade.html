Política de privacidade do Postador E se

Última atualização: 18 de novembro de 2026.

O que é

O Postador E se é um script pessoal que envia vídeos do próprio dono para o canal dele no YouTube. Ele não tem outros usuários.

Dados acessados

  • YouTube (youtube.upload): enviar vídeos para o canal autorizado.
  • YouTube (youtube.readonly): ler o nome do canal para confirmar a autorização.

Nenhum outro dado da conta Google é lido.

Como os dados são guardados

O token de acesso fica salvo apenas no computador do dono. Nada é enviado a servidores de terceiros, vendido ou compartilhado. Os dados vão somente para as APIs do Google/YouTube, no momento do envio do vídeo.

Como revogar o acesso

A autorização pode ser removida a qualquer momento em myaccount.google.com/permissions.

Uso de dados do Google

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. Este app usa os Serviços de API do YouTube; veja também os Termos de Serviço do YouTube e a Política de Privacidade do Google.
